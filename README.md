# 桜うどん — Sakura Udon

A 2D Pokémon-style Japanese village. Walk under cherry blossoms and vermillion torii, buy ingredients at the market, cook a textured bowl, slurp it, then serve guests.

Open `index.html` over http (not `file://`) or use the Pages site after it goes live.

```
python3 -m http.server 8788
# then http://127.0.0.1:8788/
```

**WASD** walk · **E / Space** cook, talk, buy, serve · **I** bag

House special: at the kamado set **冷**, add **udon + niku + chili oil** (ice helps), then **盛る**. Five slurps pay yen and open the tables. Cook again, carry the bowl, press **E** beside a guest.
